# Keep DraftKings' scoring and lineup rules in the code

DraftKings' NFL Classic scoring rules are constants in `draftkings_scoring.py`, alongside the link to DraftKings' rules page and the date they were last checked against it. Its lineup rules (the 9 roster slots, the $50,000 salary cap and the two-game minimum) are constants in `draftkings_lineup.py`. They come from the same page and share that link and date. We don't fetch them or keep them in a database. They're a few dozen fixed numbers that the app never searches or edits, so a database would add setup and migrations for nothing. Fetching isn't an option either, because DraftKings' site blocks automated requests and returns "Access Denied". As constants, the rules are type-checked and tested, and a change goes through review like any other code. DraftKings does occasionally change its rules, so they can go stale silently. We accept that: the "last checked" date records when they were last confirmed, and a change is a one-line edit.
